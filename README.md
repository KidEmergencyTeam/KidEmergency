## 📌 프로젝트 개요

- **프로젝트 명**: Kid Emergency
- **목표**: 유아와 어린이를 대상으로 한 화재 및 지진 대피 교육 게임 개발
- **개발 기간**: 2025.02.21 ~ 2025.05.15 (약 3개월)
- **개발 환경**: Unity VR (C#)
- **개발 인원**: 총 9인
  - 개발 5인
  - 기획 4인

---

## 🎯 주요 기능

- **화재·지진 대처 훈련 시나리오**  
  유치원, 학교, 집 등 다양한 환경에서의 대피 훈련

- **소화기 조작 교육**  
  VR 환경에서의 실질적인 소화기 사용 체험

- **상황별 NPC 반응 애니메이션**  
  상황에 맞는 NPC 행동 연출 및 상호작용

---

## 🛠 사용 기술

- Unity 2022.x
- C# (VR 인터랙션 및 시스템 구현)
- XR Interaction Toolkit
- Blender / Mixamo (애니메이션 리소스 활용)
